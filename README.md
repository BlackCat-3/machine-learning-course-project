# 机器学习课设报告 配套代码

四个任务分别为植物分类、图像情感分类、中心凹定位和眼底血管分割。此仓库整理实际使用的源码、实验记录及提交文件，供课程报告复查。

## 目录与最终结果

| 任务 | 源码 | 最终榜单成绩 | 排名 |
|---|---|---:|---:|
| 植物分类 | [task1_plants](task1_plants) | Mean F1 0.9523 | 29/80 |
| 图像情感分类 | [task2_emotions](task2_emotions) | Accuracy 0.722 | 40/74 |

成绩以 2026-11-08 核实的比赛结束后榜单为准。任务一、二页面说明公私榜使用相同数据行；任务三、四采用最终私榜。最终 CSV 位于 [results](results)。

## 实验材料与复现

- [运行说明](REPRODUCE.md)：数据位置、环境、训练及推理入口。
- [实验记录](experiment_records)：原有配置、日志、选型和核验结果；保留原目录结构。
- [复制清单](SOURCE_MANIFEST.json)：每个整理来源文件的 SHA256，源码未改动算法。
- `HISTORY.md` 及记录中的说明写于实验当时，其中“未提交”“线上未知”或当时排名属于历史状态；最终成绩以上表为准。

原始数据集、图像、虚拟环境、特征缓存和大型模型权重不随代码仓库上传，均仍保存在原电脑。请从课程渠道获取数据；公开权重来源见各任务说明。老师如需核对保存的本地权重，可按记录中的哈希与原文件对应。

历史记录放在 `experiment_records/`，不冒充可直接复用的运行目录。只复制配置或 completed/status 文件而缺少模型权重，会使某些脚本误判训练已完成；因此从头运行应使用新输出目录，或同时恢复完整数据、缓存和权重。

开发集、OOF、训练拟合、转换代理指标及线上分数分别记录。任务四最终 DRIVE 权重已训练过全部本地训练图，不能将其训练图拟合分数当作独立验证。本仓库不声称未完成的实验已经完成。
