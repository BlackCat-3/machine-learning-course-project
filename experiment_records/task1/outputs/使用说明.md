# 植物分类基线使用说明

`plant_baseline.py` 直接读取 `2026task1.zip`，使用预训练 ResNet18 对五种植物分类。它将每类 100 张训练图片按 80:20 分层划分，以验证集的 macro F1 选择最佳训练轮次，并生成与样例顺序一致的 `submission.csv`。

本脚本提供两种输入归一化方式：`--normalization imagenet` 使用原始预训练统计量；`--normalization train` 只从当前训练集计算 RGB 均值和标准差。详细方法和实测结果见 [归一化对照实验.md](归一化对照实验.md)。

当前机器运行时，请在本文件所在的 `outputs` 目录打开 PowerShell：

```powershell
$env:PYTHONPATH = (Resolve-Path '..\work\deps').Path
python .\plant_baseline.py --zip 'D:\Downloads\2026task1.zip' --out '.\plant_run_train_norm' --normalization train --epochs 10 --warmup-epochs 2 --batch-size 32
```

训练后生成 `submission.csv`、`validation.json`、`best_model.pt`。`submission.csv` 可上传到 Kaggle；课程规则要求单人完成、队伍名为学号、使用深度学习方法。当前本机运行的对照结果位于 `plant_run_imagenet_norm` 和 `plant_run_train_norm`。
