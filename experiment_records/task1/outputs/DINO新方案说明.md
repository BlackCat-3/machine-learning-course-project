# DINOv2 植物分类新方案

基准提交：`dinov2_base_fg_submission.csv`。本地嵌套五折 macro F1 为 **0.9538486757**；用户于 2026-09-25 回报该文件的 **Kaggle 实际得分为 0.9550**。本地验证与线上成绩分别记录。

## 方法

使用 [Meta 官方 DINOv2](https://github.com/facebookresearch/dinov2) 的通用预训练 ViT-B/14 权重提取特征，主干保持冻结。本任务的监督标签只来自作业提供的 500 张训练图。训练一个带 L2 正则化的五分类线性 softmax 层；代码使用逻辑回归优化器拟合该层，它与神经网络中的线性层加 softmax 相对应。

图片保持完整画面，统一缩放到 336×336，按预训练模型的 ImageNet RGB 均值和标准差归一化。分别提取原图和旋转 180 度图的特征。用固定的绿色像素规则给图像块特征加权，使分类层更关注植株区域；没有裁掉输入图片。训练时两个方向属于同一张原始图片，一起进入该图片所属的训练折或验证折。

绿色规则为 RGB 值缩放到 [0,1] 后 `G > 1.05R`、`G > 1.05B` 且 `G > 0.1`。每个 14×14 图像块的绿色像素占比作为池化权重；绿色区域不足时退回均匀池化。

## 验证与结果

沿用原来的分层五折划分，每折训练 400 张、留出 100 张，各类别每折留出 20 张。每个外层训练折内部再做三折验证，选择特征组合及正则化强度。标准化器也只在当前训练部分拟合。外层留出标签不参与本折参数选择。

| 外层折 | 留出集 macro F1 |
|---|---:|
| 1 | 0.9502 |
| 2 | 0.9497 |
| 3 | 0.9597 |
| 4 | 0.9694 |
| 5 | 0.9400 |

合并 500 张留出预测：**macro F1 0.9538，错误 23 张**。原 ResNet18 五折为 OOF 0.8909、错误 54 张，实际 Kaggle 0.8756。两者评估方案不同：原模型在外层验证集选择最佳训练轮次，存在一定乐观偏差；本方案在训练部分内部选择分类层参数。上述分数仍用于比较整体方法，并不是独立测试集成绩。

| 类别 | 新方案 OOF F1 |
|---|---:|
| Black-grass | 0.8980 |
| Common wheat | 0.9655 |
| Loose Silky-bent | 0.9208 |
| Scentless Mayweed | 0.9950 |
| Sugar beet | 0.9900 |

同一 Base 主干不使用绿色区域特征时，嵌套五折为 **0.9401**。使用绿色区域后为 **0.9538**。外层训练部分内部再训练多个分类层进行平均，外层得分 **0.9537**，没有带来进一步提升；与 DINOv2 Small 等权平均为 **0.9398**，也不采用。

最终根据内层验证结果确定绿色区域特征和正则化强度 C=1，在全部 500 张训练图的两个方向特征上拟合分类层。测试图片的两个方向概率取平均后输出类别。本方案是冻结主干的迁移学习，未从头训练主干，也未更新主干权重。
