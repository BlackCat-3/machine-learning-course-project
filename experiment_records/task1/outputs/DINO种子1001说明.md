日期：2026-09-25。

文件：`dinov2_new_seed_submission.csv`。这是模型实际生成的另一份提交，与已取得 Kaggle 0.9550 的 `dinov2_base_fg_submission.csv` 有 **1 张测试图片的分类不同**。没有手工修改预测标签，也没有用测试标签选择模型。

## 搜索结果

上一轮的 5 个种子未超过原方案。本轮增加 314、2718、3407、888、1024、2025、2027、2028、100、777 共 10 个种子，分别比较随机内部选参、训练子集集成及跨种子集成，仍未超过原方案。

## 训练方法

冻结 DINOv2 Base 主干，复用原图与 180 度旋转图特征。外层验证折不参与本折分类层选参、标准化或拟合。每个外层训练部分用原方案的内部三折选参方法，种子 1001 控制分层五折子集，每个分类层使用外层训练部分的 80%，五个分类层平均概率。

最终生成提交时，沿用原方案根据内部验证选择的绿色区域特征（索引 3840:4608）和 C=1，在全部 500 张训练图片中用种子 1001 做分层五折；分别训练五个各使用 400 张原始图片及其旋转视图的分类层，输出概率取平均。每个原始样本在五个模型中参与训练四次。

## 文件及复现

- `plant_resample_search.py`：训练子集种子搜索，在首个超过原方案的种子处停止。
- `plant_seed_confirm.py`：导出模型，核对提交差异，并按另外两套划分复核。
- `dinov2_resample_search/comparison.json`：1000 和 1001 的搜索结果。
- `dinov2_resample_search/confirmation/confirmation.json`：选中种子、全部最终训练子集、配置、复核结果及文件哈希。
- `dinov2_resample_search/confirmation/resample_1001_seed_1001_head_0.npz` 至 `head_4.npz`：最终五个分类层及各自标准化参数。
- `dinov2_resample_search/confirmation/test_probabilities.npy`：378 张测试图片的五分类概率。
- `dinov2_new_seed_submission.csv`：新候选提交，已验证表头、378 个唯一 ID、样例 ID 顺序和合法类别。

在项目根目录执行：

```powershell
python outputs/plant_resample_search.py
python outputs/plant_seed_confirm.py --search outputs/dinov2_resample_search --candidate resample_1001
```

新文件输出来自保存的五个分类层；已经核对导出权重的推理概率与训练管线一致。
